# -3D--
Этот проект — о том, как школьник может превратить 3D-принтер в инструмент национального значения. В условиях санкций и дефицита импортных комплектующих предлагается модель локального производства. Проект с социальной миссией: вернуть заводам рабочие станки, а стране — технологическую независимость.
